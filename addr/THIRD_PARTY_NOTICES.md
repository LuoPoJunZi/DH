# 来源说明

本目录 worker.js 及 data/、server/ 中的 JavaScript 模块改编自 [jiangnan1224/AddressGenerator 的 feature/real-addresses 分支](https://github.com/jiangnan1224/AddressGenerator/tree/feature/real-addresses)。上游 README 声明 MIT License，原作者注释在拆分模块中保留。改动包括 Cloudflare Pages 接入、请求取消、有限超时、响应大小限制、候选缓存和 DH 页面适配。

地址数据来自 OpenStreetMap contributors，遵循 ODbL。旧版收藏与导出代码来自项目所有者提供的模块；原许可证保存在 LICENSE 文件中。
